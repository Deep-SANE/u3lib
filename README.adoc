= U3Lib

C++ library for fast and accurate evaluation of U(3) Wigner coupling and Racah recoupling coefficients

Paper: https://doi.org/10.1140/epjp/s13360-024-05501-8

Manual: https://gitlab.com/qcx3/u3lib/-/jobs/artifacts/devel/browse?job=manual

== Tests

After sourcing your usual qcx-config environment, run `make test` from this
directory. Every invocation recompiles and runs all test executables, reporting
what is checked and whether it passes without dumping coefficient values.

See link:test/README.md[test documentation] for coverage and tolerances, and
link:test/reference/README.md[reference-data documentation] for the saved
coefficient values, conventions, and generation procedure.
