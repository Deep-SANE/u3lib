# Physical-to-canonical transformation

Read [shared runtime instructions](../runtime.md). Use the free functions in
[U3SO3_to_U3U2U1.h](../../../include/U3SO3_to_U3U2U1.h):

API signatures (reference only):

```text
std::pair<std::vector<int>, Eigen::MatrixXd>
u3::phys_to_cano(const u3::physicalvector& p, int M,
                 const std::vector<u3::gelfand>& gArr);

std::pair<std::vector<std::vector<int>>, std::vector<Eigen::MatrixXd>>
u3::phys_to_cano_allM(const u3::physicalvector& p,
                      const std::vector<u3::gelfand>& gArr);
```

They express the physical state with specified M `|(lambda,mu) kappa L M>` in the
canonical Gelfand basis. This is the basis change that [phys-coupling](../phys-coupling/SKILL.md)
and [phys-generators](../phys-generators/SKILL.md) call internally; it is **not**
SU(3) conjugation ([conjugation](../conjugation/SKILL.md)) and not a generator
action ([cano-generators](../cano-generators/SKILL.md)).
The driver [src/U3SO3_to_U3U2U1.cpp](../../../src/U3SO3_to_U3U2U1.cpp) illustrates
these functions.

## Inputs, output and conventions

- Use a normalized irrep (`n33=0`) and validate `0 <= L <= lambda+mu`
  before constructing `p = u3::physicalvector(irrep, L)`. Require
  `p.kappa()>0` and `|M|<=L`, then construct `gArr = u3::gelfandBasis(p.irr())`.
- `phys_to_cano(p,M,gArr)` returns `(canoBasis, T)`: `canoBasis` are indices into
  `gArr` of the Gelfand states at this `M` (those with `e11-e22 == M`), and `T`
  is `(canoBasis.size() x p.kappa())`. **Column `k` is the expansion of the
  k-th SO(3) multiplicity copy** `kappa=k+1`; row `r` is the amplitude on
  `gArr[canoBasis[r]]`. `phys_to_cano_allM` returns the same for every
  `M = L..-L` as parallel vectors indexed `x = L - M`.
- Phase convention (documented in the header, do not alter): the SO(3) highest-weight state `M=L` is fixed by the null-space solve (or, for `lambda>mu`, mapped from the
  conjugate irrep with phase `(-1)^(n22+n11-L)`, with n22,n11 taken from the conjugate pattern); `L_-` then fixes all lower-M
  phases within a kappa multiplet; `M<0` is generated by the within-irrep M-reflection relation
  with phase `(-1)^(lambda+L+n22)`. For a self-conjugate irrep `(n,n)` the solver
  fixes a valid multiplicity basis that need **not** diagonalize conjugation and
  can mix kappa (e.g. `(4,4)` L=2); do not replace the kappa basis with a scalar
  phase or realign it to another convention. Any kappa rotation must be applied
  to coupling coefficients too.

## Executable driver and checks

Drop this in `src/` (or compile against the library's configured flags). The
orthonormality of the columns is a convention-independent check.

```cpp
#include <u3lib.h>
#include <cassert>
#include <cmath>
#include <vector>
#include <Eigen/Dense>
#include <U3basis.h>
#include <U3SO3_to_U3U2U1.h>

int main(int argc, char* argv[])
{
  u3::initialize(&argc, &argv);
  auto close = [](double a, double b) { return std::abs(a - b) < 1e-5; };

  u3::irrep ir(2, 0);
  auto gArr = u3::gelfandBasis(ir);
  u3::physicalvector p(ir, 2);                 // |(2,0) L=2>, kappa_max = 1

  // M = L = 2: a single Gelfand state, the highest weight, amplitude 1.
  auto [cb2, T2] = u3::phys_to_cano(p, 2, gArr);
  assert(T2.rows() == 1 && T2.cols() == 1);
  assert(close(T2(0, 0), 1.0));

  // M = 0: spreads over two Gelfand states with amplitudes sqrt(1/3), sqrt(2/3).
  auto [cb0, T0] = u3::phys_to_cano(p, 0, gArr);
  assert(T0.rows() == 2 && T0.cols() == 1);
  assert(close(T0(0, 0), std::sqrt(1.0 / 3.0)));
  assert(close(T0(1, 0), std::sqrt(2.0 / 3.0)));

  // Columns are orthonormal for every M: T^T T = I_kappa.
  Eigen::MatrixXd gram = T0.transpose() * T0;
  assert(close(gram(0, 0), 1.0));

  // All-M form agrees with the per-M form (x = L - M).
  auto [cbAll, Tall] = u3::phys_to_cano_allM(p, gArr);
  assert(close(Tall[2 - 0](0, 0), T0(0, 0)));  // x = L - M = 2 for M = 0
  u3::finalize();
}
```

## Presentation and checks

Return, per requested `M`, the Gelfand states (`canoBasis` into `gArr`) with the
amplitude matrix, labelling rows by state and columns by `kappa` (1-based). State
that this is the expansion at fixed M, not a coupling coefficient. Verify
`T^T T = I_kappa` (orthonormal multiplicity columns) at each M, that the `M=L`
block contains the SO(3) highest-weight states, and that `phys_to_cano_allM` reproduces the
per-M results. Do not rescale columns or drop the kappa mixing of a
self-conjugate irrep to force a diagonal form.
